## 一、查看现有版本

**1.**点开项目--外部库(External Libraries)--就可以看到python目前的版本了，我的是3.11的版本

## 二、文件设置切换python版本

**2.**文件(File)--设置(Settings)，或者直接使用快捷键Ctrl+Alt+S打开设置

![](https://i-blog.csdnimg.cn/direct/3ff1cd425183425d95ccc81eb15ae501.png)

**3.** 项目(project:place)--python解释器(python interperter)--展开--全部显示

![](https://i-blog.csdnimg.cn/direct/a00e03d1c84748deabef8507206a84a5.png)

4.修改为你现在要使用版本的路径。点击文件浏览--找到要切换的python版本的exe文件，然后复制这个路径---粘贴到解释权的路径那里

![](https://i-blog.csdnimg.cn/direct/7a23c22c5d2446bfafe7a745ff43e553.png)

**5.**把要更换的python版本路径粘贴到解释权路径里面--点击应用--确定，这样就更换完成了

![](https://i-blog.csdnimg.cn/direct/c9550ea613e44cf29a6cb5a02f50f89b.png)

## 三、查看是否切换成功

**6.**任意运行一个文件，可以在控制台看到目前所使用的版本

![](https://i-blog.csdnimg.cn/direct/f02adec2f89b409b8d3f8d8892076680.png)
