1.打开PyCharm并选择创建新项目

首先，启动 PyCharm，你会看到欢迎界面。在这里，选择"Create New Project"或者"新建项目"。

![使用Pycharm创建新的Python项目_pycharm创建新项目-CSDN博客_rId9.png](../images/使用Pycharm创建新的Python项目_pycharm创建新项目-CSDN博客_rId9.png){width="5.833333333333333in" height="4.213836395450569in"}

2.选择项目 类 型和环境

![使用Pycharm创建新的Python项目_pycharm创建新项目-CSDN博客_rId12.png](../images/使用Pycharm创建新的Python项目_pycharm创建新项目-CSDN博客_rId12.png){width="5.833333333333333in" height="4.213836395450569in"}

①选择 Python 作为项目类型，

②选择Virtual Environment（虚拟环境）作为项目环境。此步骤的关键在于使用虚拟环境来管理项目依赖性。

③选择虚拟环境python关联版本

④创建

注：选择虚拟环境：也可以自定义环境进行创建，通常会选择（生成新的） 或 （选择现有）。 建议选择 （生成新的），这样做Python环境不会和其他项目有冲突

![使用Pycharm创建新的Python项目_pycharm创建新项目-CSDN博客_rId15.png](../images/使用Pycharm创建新的Python项目_pycharm创建新项目-CSDN博客_rId15.png){width="5.833333333333333in" height="2.5786417322834647in"}

3.命名项目并选择项目位置

在项目名称框中输入你的项目名称（如PythonProject_new），并选择一个合适的目录来保存该项目。

![使用Pycharm创建新的Python项目_pycharm创建新项目-CSDN博客_rId18.png](../images/使用Pycharm创建新的Python项目_pycharm创建新项目-CSDN博客_rId18.png){width="5.833333333333333in" height="1.6462160979877516in"}

4.创建项目

点击创建后，PyCharm 会自动生成项目结构，包括 venv 和main.py。venv 是虚拟环境的 文件夹 ,

项目的主文件。

![使用Pycharm创建新的Python项目_pycharm创建新项目-CSDN博客_rId21.png](../images/使用Pycharm创建新的Python项目_pycharm创建新项目-CSDN博客_rId21.png){width="2.7222222222222223in" height="1.9305555555555556in"}

5.查看生成的项目结构

创建完成后，你可以在 PyCharm 的项目窗口中看到以下结构:

> MyProject
>
> \|--- venv #虚拟环境文件夹
>
> \|--- Scripts \# Windows 上的执行文件
>
> \|--- lib \# 安装包文件
>
> \|--- main.py \# 项目的主 Python 文件
