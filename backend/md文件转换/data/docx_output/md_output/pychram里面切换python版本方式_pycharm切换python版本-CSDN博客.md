## 一、查看现有版本

**1.**点开项目--外部库(External Libraries)--就可以看到python目前的版本了，我的是3.11的版本

## 二、文件设置切换python版本

**2.**文件(File)--设置(Settings)，或者直接使用快捷键Ctrl+Alt+S打开设置

![pychram里面切换python版本方式_pycharm切换python版本-CSDN博客_rId11.png](../images/pychram里面切换python版本方式_pycharm切换python版本-CSDN博客_rId11.png){width="5.833333333333333in" height="3.660323709536308in"}

**3.** 项目(project:place)--python解释器(python interperter)--展开--全部显示

![pychram里面切换python版本方式_pycharm切换python版本-CSDN博客_rId14.png](../images/pychram里面切换python版本方式_pycharm切换python版本-CSDN博客_rId14.png){width="5.833333333333333in" height="4.380880358705162in"}

4.修改为你现在要使用版本的路径。点击文件浏览--找到要切换的python版本的exe文件，然后复制这个路径---粘贴到解释权的路径那里

![pychram里面切换python版本方式_pycharm切换python版本-CSDN博客_rId17.png](../images/pychram里面切换python版本方式_pycharm切换python版本-CSDN博客_rId17.png){width="5.833333333333333in" height="5.039227909011373in"}

**5.**把要更换的python版本路径粘贴到解释权路径里面--点击应用--确定，这样就更换完成了

![pychram里面切换python版本方式_pycharm切换python版本-CSDN博客_rId20.png](../images/pychram里面切换python版本方式_pycharm切换python版本-CSDN博客_rId20.png){width="5.833333333333333in" height="5.03886811023622in"}

## 三、查看是否切换成功

**6.**任意运行一个文件，可以在控制台看到目前所使用的版本
